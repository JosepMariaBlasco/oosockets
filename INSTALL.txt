Installing ooSockets
====================

ooSockets is two files: sockets.cls, and its native library
(oosockets.dll on Windows, liboosockets.dylib on macOS, liboosockets.so
on Linux); on Windows, also OpenSSL's two DLLs. Put them where ooRexx
finds them:

  Windows: the files in ooRexx's bin directory (the one with rexx.exe):
  oosockets.dll, sockets.cls, and OpenSSL's libssl-3-x64.dll and
  libcrypto-3-x64.dll, which go next to oosockets.dll.

  macOS, Linux: the library in ooRexx's lib directory (the one with
  librexx), sockets.cls in ooRexx's bin directory (the one with rexx).
  With the installers, those are /usr/local/lib and /usr/local/bin;
  with the portable zips, lib/ and bin/ inside the unpacked directory.

Then, in a program:

  ::requires "sockets.cls"

Instead of ooRexx's directories, any directory works if it is on
REXX_PATH (for sockets.cls) and on the library path (PATH on Windows,
DYLD_LIBRARY_PATH on macOS, LD_LIBRARY_PATH on Linux) for the library.

What each zip needs:

  Windows: 64-bit. TLS is Windows' own (Schannel). OpenSSL 3, in the
           two DLLs of the zip (licence: OpenSSL-LICENSE.txt), is
           loaded only for DTLS and with OOSOCKETS_TLS=openssl
           (environment variable: OpenSSL for everything). Without the
           DLLs everything works but the DTLS server, and the DTLS client
           is then Windows' own, which cannot tell a server it closes.
           Another OpenSSL 3: its directory (the one with
           libssl-3-x64.dll) in OOSOCKETS_OPENSSL.
  macOS:   macOS 11 or later on Apple Silicon, 10.14 or later on Intel.
           For TLS and DTLS, OpenSSL 3 from Homebrew or MacPorts, which
           keep it up to date:
             brew install openssl@3       (Homebrew)
             sudo port install openssl3   (MacPorts)
           ooSockets brings no OpenSSL of its own. Without it, the plain
           sockets work, and TLS says what to install. Another
           OpenSSL 3: its directory (the one with libssl.3.dylib) in the
           environment variable OOSOCKETS_OPENSSL.
  Linux:   x86_64; glibc 2.35 or later and OpenSSL 3
           (libssl.so.3), as in Ubuntu 22.04 and later, Debian 12,
           Fedora, and others. Another OpenSSL 3: its directory in
           OOSOCKETS_OPENSSL.

ooRexx: 5.3.0 beta, trunk r13344 or later (tested with r13344 and the
newest beta build). ooSockets is a beta, as ooRexx 5.3.0 is, and leaves
beta with it. ooRexx 5.2.0 is not supported: its interpreter crashes now
and then in programs with several activities (a server that serves each
client in an activity of its own), which 5.3.0 has fixed.
